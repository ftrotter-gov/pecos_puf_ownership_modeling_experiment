How to read this

Ultimate owner. An entity with no organizational owner above it in PECOS.

Orgs vs. Hospitals. Orgs counts provider organizations (distinct Medicare enrollments); Hospitals counts the CCN-identified facilities beneath them. Hospitals exceeds orgs for most chains, because one organization often operates several certified facilities.

Joint ventures. A provider organization with more than one ultimate owner. It is counted under each owner, so the Orgs column sums to more than the total number of hospitals.

Depth. How many ownership hops PECOS recorded between the hospital and this owner.

Individuals are excluded. Only organization-to-organization ownership forms the chain. Physician owners and board members appear in the source data but are not part of the corporate hierarchy.

⚠️ These counts have real limitations. Owners are only partly de-duplicated, index funds rank near the top, and the joint-venture flag is approximate. Read the caveats before quoting any number here.
